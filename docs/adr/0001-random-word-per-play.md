# Random word per play instead of a shared daily word

GuestWorld is explicitly Wordle-inspired, and Wordle's signature mechanic is a single word shared by all players per calendar day (enabling comparison and social sharing of results). We chose instead to pick a fresh random word from the word list every time a game starts, with unlimited replay and no persisted stats. This was a deliberate trade-off: a daily word drives social/retention value but requires date-based seeding and pairs naturally with persisted stats (streaks, history) — both of which we're explicitly not building. Random-per-play keeps the game simpler to build, fully client-side, and more fun to replay casually, at the cost of the "everyone compares today's result" hook that makes Wordle itself notable.
