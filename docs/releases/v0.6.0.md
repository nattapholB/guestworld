# v0.6.0 — Sudoku Local Auto-Save

Sudoku now auto-saves unfinished puzzles and preferences locally in your browser using GuestWorld's shared persistence layer, matching Crossword's seamless resume experience.

## Added

- Automatic `localStorage` persistence for the latest unfinished Sudoku puzzle (`guestworld:sudoku:round:v1` via `src/app/storage.ts`), saving board entries, candidate notes, selected cell, hints used, and elapsed time on edits, selection, hints, help open, `Games` exit, `pagehide`, and `visibilitychange` (hidden).
- Persistent `Show before each puzzle` help preference (`guestworld:sudoku:prefs:v1`) across reloads, with graceful session-only fallback if browser storage is blocked.
- Strict snapshot validation (`isValidSavedSudokuRound`) guarding against corrupted, completed, invalid-bitmask, or given-tampered saved state.
- Reusable `.resume-banner` on Sudoku setup showing difficulty, filled cell progress (`N/81 filled`), elapsed time, `Resume puzzle`, and `Discard`, plus a confirmation modal (`Start a new puzzle?`) before replacing a saved round.

## Improved

- Clicking `Games` during an unfinished Sudoku now saves progress directly and returns to the hub, retiring the old `"Leave puzzle? Your progress will be lost."` dialog.
- Resumed rounds keep storage compact by intentionally excluding Undo history and active Notes mode (resetting cleanly on resume), and saved rounds clear automatically upon completion or discard.
- Updated Sudoku setup footnote and How to play modal copy to reflect automatic browser saving.
- Expanded `tests/sudoku.test.ts` and `tests/browser_smoke.py` to cover Sudoku auto-save, resume, completion clearing, discard, persisted help preference, snapshot validation, and the 3-card hub + reload resume flow.
