# v0.7.2 — Centered Modal Dialogs

Fixes off-center `HOW TO PLAY` (and confirmation/install) modals on tablet and desktop viewports across Chromium and WebKit/Safari.

## Fixed

- **Modal dialog horizontal centering:** `.game-dialog` previously relied on intrinsic `fit-content` sizing while its child `.howto-card` constrained itself with `width: min(460px, 100%)`. Unwrapped list items inside `<dialog>` expanded `<dialog>` up to `~1036px` while `.howto-card` stayed `460px` flush left. Explicitly sizing `.game-dialog` (`width: min(460px, calc(100vw - 32px - env(safe-area-inset-left) - env(safe-area-inset-right)))`, `margin: auto`, safe-area-aware max bounds) and setting `.game-dialog .howto-card { width: 100%; }` keeps every modal centered on iPhone 15 Pro (`393×852`), iPad (`768×1024`), and Desktop (`1280×800`).
