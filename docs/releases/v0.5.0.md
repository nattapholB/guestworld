# v0.5.0 — Crossword & Local Auto-Save

GuestWorld now expands to three cosmic puzzles, adding a bilingual Crossword with local auto-save alongside Orbit Word and Sudoku.

## Added

- Crossword as the third game on the GuestWorld hub with a custom 1024×1024 cosmic pixel-art cover (`crossword-cover.jpg`) matching Orbit Word and Sudoku.
- Three board sizes (`Mini` 5×5, `Classic` 7×7, `Grand` 9×9) generated dynamically on each round across 56 distinct validated grid patterns and a curated bilingual lexicon of 2,348 familiar 4–7 letter English words.
- Offline `EN / ไทย` clue language toggle in the active clue banner, backed by bundled Fontsource Noto Sans Thai (`public/licenses/Noto-Sans-Thai-OFL.txt`).
- Crossword play tools (`Check`, `Erase`, `Hint`, `Reveal Word`), full physical keyboard navigation, toggleable desktop / automatic mobile on-screen QWERTY keyboard, pause-aware elapsed clock, and automatic completion with no mistake limit.
- Reusable versioned `localStorage` persistence helper (`src/app/storage.ts`) powering automatic Crossword save/resume (including the Setup Resume banner and overwrite confirmation modal) and structured for future Sudoku adoption.

## Improved

- GuestWorld hub updated to a responsive 3-card layout (3 columns desktop, 2 columns tablet, 1 column mobile).
- Automated test suite expanded to 23 tests (`tests/crossword.test.ts` and `tests/sudoku.test.ts`) covering storage error handling, bilingual lexicon integrity, all 56 grid patterns, generator validity, and round lifecycle/persistence.
