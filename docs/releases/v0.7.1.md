# v0.7.1 — Responsive Keyboard & iPhone PWA Polish

Fixes keyboard overflow across Orbit Word, Crossword, and Sudoku when installed as a standalone PWA or viewed on narrow portrait screens (verified against iPhone 15 Pro `393×852` and desktop `1280×800` / `1024×768`).

## Fixed

- **Orbit Word 3D keyboard framing:** Added `getCameraDistance` in `src/components/Background/cameraFraming.ts` and updated `ParallaxRig` and `CelebrationRig` so the Three.js camera pulls back on narrow/portrait aspect ratios (`REQUIRED_HALF_WIDTH = 3.55`), keeping all 3D keys (`Q`/`P`, `ENTER`/`BACK`) inside the viewport with side margin while keeping desktop distance at `10.5`. Also snapped the initial camera distance on frame 1 and scaled parallax drift on narrow screens.
- **Crossword on-screen keyboard overflow:**
  - On desktop (`>= 769px`), opening `⌨ Keys` adds `.has-keyboard` and caps `.crossword-board` height (`calc(100dvh - 410px)`) so the keyboard fits within the viewport without vertical scrolling.
  - On mobile (`<= 640px`), tightened vertical spacing and bounded `.crossword-board` with `100dvh` and `env(safe-area-inset-top / bottom)` so the header, active clue, grid, and QWERTY keyboard fit cleanly above the iPhone Home Indicator.
  - Scoped active-clue auto-scrolling inside `.crossword-clues` (`cluesRef`) instead of calling `scrollIntoView` on the document viewport.
- **Sudoku mobile spacing:** Tightened vertical spacing under `@media (max-width: 640px)` so the board, number pad, and tool buttons fit comfortably inside `393×852`.

## Tests

- Added `tests/camera.test.ts` verifying responsive camera distance on desktop, iPhone 15 Pro portrait/landscape, and invalid aspect fallbacks (`npm test`: 33 tests).
