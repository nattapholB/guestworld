# v0.7.3 — Responsive HUD, Scroll Reset & Tablet Layout Polish

Polishes mobile, small-screen, and tablet UI across Orbit Word, Sudoku, and Crossword (verified on iPhone 15 Pro `393×852` in Chromium and WebKit, `320×640`, and iPad `768×1024`).

## Fixed

- **Screen navigation scroll reset:** Navigating between the hub, setup screens, and active games in `App` now resets `window.scrollTo(0, 0)`, preventing scrolled hub offsets from hiding the `← Back to games` link or game header on the next screen.
- **Orbit Word HUD responsiveness:** Added `white-space: nowrap` to `.hud-item` and `.hud-menu-link`, tightened `.hud-bar` spacing on mobile (`≤640px`), and added a wrapping fallback at `≤360px` so `"How to play"` stays single-line on iPhone 15 Pro (`393×852`) and the bar never overflows on `320px` screens.
- **Tablet Crossword keyboard fit (`641px–768px`):** Added a viewport-aware `max-width` clamp (`calc(100dvh - 520px - env(safe-area-inset-top) - env(safe-area-inset-bottom))`) to `.crossword-board` inside `@media (max-width: 768px)` so the 9×9 Grand board and all three QWERTY keyboard rows fit above the fold on iPad portrait (`768×1024`).
- **Orbit Word end overlay spacing:** Added safe-area horizontal padding to `.end-overlay`, responsive `width: min(420px, 100%)` to `.end-card`, and wrapping to `.end-stats` / `.end-actions` so the result card keeps clean side margins on narrow phones.
- **Mobile touch targets & Crossword contrast:** Enlarged `.back-link` (`44px`), `.hud-menu-link` (`36px`), `.cw-step-btn` (`36×36px`), `.cw-dir-badge` (`36px`), and `.cw-lang-btn` (`32px`), and increased contrast between playable Crossword cells (`#1b254a`), active-word highlights (`#243b6b`), and dark blocks (`#040614`).
