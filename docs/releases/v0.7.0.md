# v0.7.0 — Offline PWA Support & Mobile Polish

GuestWorld is now an installable offline-first app: add it to your home screen or desktop and play Orbit Word, Sudoku, and Crossword without a connection.

## Added

- Progressive Web App support via `vite-plugin-pwa` (`manifest.webmanifest`, `sw.js`) with a Workbox precache of the full app shell, covers, fonts, licenses, icons, and the lazy 3D `Scene-*.js` chunk (`maximumFileSizeToCacheInBytes: 3 MiB`). Relative `./` `id`, `start_url`, and `scope` keep it working under the GitHub Pages `/guestworld/` subpath.
- `Install App` button on the game hub footer for browsers that offer a native install prompt, plus an iOS Safari `Add to Home Screen` guide modal (`Share` → `Add to Home Screen` → `Add`). Both stay hidden once installed.
- `Offline` status pill on the hub that appears when the browser loses its connection.
- Non-blocking bottom `Update available` toast (`Reload` / `Later`) when a new version is ready; the app also checks for updates when the tab becomes visible again.
- Cosmic pixel-art `GW` app icons: 192 and 512 `any`, a 512 maskable icon, `apple-touch-icon.png` (180×180), `favicon.ico`, and a 32×32 PNG favicon.
- `tests/pwa.test.ts` covering standalone detection, iOS Safari detection, install-mode selection, install-prompt handling, and `index.html` PWA metadata.

## Improved

- `index.html` adds `viewport-fit=cover`, `theme-color`, Apple web-app meta tags, relative icon links, and a title/description that mention Crossword.
- Mobile and standalone polish: safe-area insets on the hub, setup, HUD, Sudoku, and Crossword screens, `touch-action: manipulation` on buttons and puzzle cells, and `overscroll-behavior-y: none` to stop pull-to-refresh bounce.
