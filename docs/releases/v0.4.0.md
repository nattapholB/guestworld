# v0.4.0 — GuestWorld and Sudoku

GuestWorld now brings Orbit Word and Sudoku together in one game hub.

## Added

- GuestWorld game selection with the supplied Orbit Word and Sudoku cover artwork.
- Sudoku with three logically graded difficulties and 20 uniquely solvable puzzles per level.
- Notes, Undo, Erase, and Hint; duplicate highlighting with unlimited corrections.
- Elapsed time that pauses during help and exit confirmation, plus completion stats and replay.
- Responsive Sudoku board and controls with keyboard navigation.

## Improved

- Shared dialogs contain focus, restore it on close, and support Escape.
- Game-specific keyboard input is isolated; Enter on a navigation button no longer also submits a Word guess.
- Fonts are served locally, and cover assets are optimized while preserving their full artwork.
- Automated rule/content/lifecycle checks now run before the Pages build.

Sudoku progress is session-only and is discarded when leaving or reloading. This release does not introduce accounts, saved games, scores, or historical statistics for Sudoku.
